## 発表の流れ(案)

1. 大雪の予報 → 若者に通知(今ある)
2. お年寄りが「たすけて」→ 家族の LINE にも届く(6)
3. 若者が友だちを誘って一緒に参加(4)→ 本人確認(今ある)
4. 向かっている間、お年寄りの画面の地図に若者のアイコンと「あと約 5 分」(7)→ 玄関で合言葉(3)
5. スマホをポケットに入れて雪かき。スコップ計の数字が増えていく(1)
6. 終わったら結果の画面。お年寄りから星のいいねが届く
7. ランキングで、最後の 1 人が加わって町の灯りが満開に、「×2 達成!」(2)
