# 提案 4: 雪スキャン(写真で雪の量を測る)— 調査と試作

雪かきの前と後の写真から「どれだけ雪が減ったか」を、**スマホの中の AI と画像処理** で測ります。
「こんな実装できるんだ」と言える技術の主役の候補です。試作の画面は `/liff/snow-scan.html`(ログインなしで開ける)。

## 結論

- **作れた**: 写真 → 雪の部分を見つける → 奥行きの AI で遠近を補正 → 除雪率、を **スマホのブラウザの中だけ** で行う試作
- 奥行きの AI(Depth Anything V2 Small)は、PC の Chrome(WebGPU)で 1 枚 0.2〜0.8 秒。モデルは約 27MB(初回だけダウンロード)
- **まだ分からない**: 本物の雪の写真での正しさ / LINE の中のブラウザで WebGPU が使えるか(使えなければ WASM で動くが遅い)
- 研究を調べると、**写真 1 枚から雪の深さ(m)を直接出す方法は確立していない**。メートルにするには基準になる物(長さが分かっている物)が必要

## しくみ(試作)

```text
① 前の写真 ─┐
            ├─ 雪の部分(明るくて色の薄い点。写真の下 60% = 地面だけ)
② 後の写真 ─┘   └─ 奥行きの AI で遠近を補正(遠い地面ほど、1 点が広い面積を表すので重く数える)
                       └─ 除雪率 = (前の雪の割合 − 後の雪の割合)÷ 前の雪の割合
```

| ファイル | 役目 |
| --- | --- |
| `public/liff/snow-scan-core.js` | 雪の色の判定・遠近補正の重み・除雪率(純粋関数。`tests/snow-scan-core.test.ts`) |
| `public/liff/depth-model.js` | 奥行きの AI を読み込んで動かす(Transformers.js 4.3.2。WebGPU → だめなら WASM) |
| `public/liff/snow-scan.js` / `.html` | 試作の画面(写真に雪の部分を水色で重ね、奥行きを色で見せる) |

工夫したところ:

- **明るさの基準を写真ごとに決める**: 夕方・日陰でも、その写真のいちばん明るいあたり(上位 5%)と比べて雪を判定する
- **遠近補正**: 写真では遠くの地面ほど小さく写る。奥行きの AI の値から「遠い点ほど重く」数える(重み = 1 ÷ 奥行き²、最大 16 倍)。空や建物に引っぱられないよう、地面の点だけで奥行きをそろえる
- **写真は送らない**: 計算はすべて端末の中。本人確認の顔の照合と同じ考え方

## 調べたこと(研究・技術)

| テーマ | 分かったこと |
| --- | --- |
| 写真 1 枚からの奥行き | Depth Anything V2 にはメートルで出す「屋外用」モデルもあるが、ブラウザ用(ONNX)の変換版は見つからなかった。ブラウザで動くのは相対的な奥行きの版(Small は Apache-2.0。Base / Large は非商用ライセンス) |
| 雪尺(目盛りの棒)の写真 | 定点カメラで雪尺を撮り、画像処理で積雪深を読む研究がある(Bongio ほか 2021 / Fernandes ほか 2019。手で読んだ値との差 1cm 程度の報告)。**長さの分かる物を写す** のが確実 |
| 写真測量(SfM) | 飛行機・ドローンの写真から立体を作って積雪深を出す研究では、誤差 15〜30cm 程度。スマホでも理屈は同じだが、玄関前の除雪には粗い |
| スマホの LiDAR | iPhone の LiDAR で積雪の変化を測れたという報告がある。ただし LINE の画面(LIFF)からは LiDAR を使えない |
| 新雪の重さ(密度) | 気温から新雪の密度を出す式がある(密度 ≒ 67.9 + 51.3 × e^(気温/2.6) kg/m³ の形。出典の確認が必要)。天気の気温と合わせれば「体積 → 重さ」を今の固定値(100kg/m³)より良くできる |

参考: [Depth Anything V2 Small(ONNX)](https://huggingface.co/onnx-community/depth-anything-v2-small)、[Metric Outdoor モデル](https://huggingface.co/depth-anything/Depth-Anything-V2-Metric-Outdoor-Large-hf)、[Bongio ほか 2021(The Cryosphere)](https://tc.copernicus.org/articles/15/369/2021/)、[Fernandes ほか(カナダ政府刊行物)](https://publications.gc.ca/site/eng/9.893835/publication.html)、[スマホ LiDAR の積雪深(AGU 2021)](https://ui.adsabs.harvard.edu/abs/2021AGUFM.C35G0964K)、[写真測量の積雪深(Frontiers 2022)](https://www.frontiersin.org/articles/10.3389/feart.2022.989792/full)、[新雪密度の式(VIC モデルのコード)](https://hydroshare.ornl.gov/files/9505/CONUSVIC4/vic411/snow_utility.c)

## 次にやること(案)

1. **本物の雪の写真で試す**(いちばん大事): 美唄で、同じ場所の前・後を何組か撮って、目で見た除雪率と比べる
2. **基準物でメートルにする**: スコップ(柄の長さが分かる)を雪に立てて撮り、雪尺の研究と同じように雪の深さを読む。奥行きの AI と組み合わせると「体積」にできる
3. **気温から雪の重さ**: 天気の気温で新雪の密度を変え、今の「× 100kg」を置き換える
4. 雪かき中の流れに入れる: 雪かきを始める前と、終えるときに 1 枚ずつ撮る(リーダーの範囲の記録の画面)

## 注意

- 前と後は **同じ場所・同じ向き・同じ高さ** から撮る必要がある(ずれると比べられない)
- 夜・街灯の色・影の青さで、雪の判定がずれることがある
- 奥行きの AI のモデルは Hugging Face から読む(初回 約 27MB)。通信の弱い場所では時間がかかる
