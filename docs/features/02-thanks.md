# 02. いいね(お年寄り向け)

## 何のための機能?

雪かきをしてくれた若者に、お年寄りが **お礼(いいね)** を送れるようにします。
いいねはそのまま [ランキング](04-ranking.md) の「評価ポイント」になります。
若者にとっては「ありがとう」が直接届くことが、また来たくなる理由になります。

## 使い方

1. 若者が雪かきを終えると、お年寄りの LINE に「〇〇さんが雪かきを終えました」と届く
2. メッセージ内の **「ありがとう」** ボタンを押す
3. 若者の LINE に「〇〇さんから ありがとう が届きました」と届く

## 画面イメージ

```text
┌──────────────────┐
│ ○○さんが          │
│ 雪かきを終えました │
│                  │
│ ┌──────────────┐ │
│ │ ありがとう 👍 │ │  ← ボタン 1 つで完了
│ └──────────────┘ │
└──────────────────┘
```

LIFF 画面を開かなくても、**トークに届いたメッセージのボタンを押すだけ** で済む形を目指します
(LINE の「Flex Message」や「ボタンテンプレート」という仕組みで作れます)。

## ルール

- 1 回の雪かきにつき、いいねは 1 回まで
- 押さなくても雪かき自体は完了扱い(押し忘れで若者が損をしすぎないようにする)
- いいねが押されたことで「本当に雪かきをした」確認にもなる

## デモで作る範囲

- 完了メッセージに「ありがとう」ボタンを付ける
- 押すと若者にポイントが入り、若者に通知が届く

## あと回しにすること

- 星 5 段階などの細かい評価
- 一言メッセージを添える機能
