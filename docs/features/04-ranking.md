# 04. ランキング(若者向け)

## 何のための機能?

雪かきを **ゲームのように競える** ようにします。
「普段は運動しないけど、ジムには行きたくない」という若者が、ランキングを目当てに雪かきに来るのがねらいです。
レイドバトル(= みんなで協力して大きな敵を倒すゲーム)のように、**仲間と一緒に行くほど得をする** 仕組みにします。

## ポイントの種類

美唄と関わる人を増やす、というアプリの目的に合わせて 4 種類にします。

| ポイント | 何をしたらもらえる | 目的とのつながり | 例(仮の値) |
| --- | --- | --- | --- |
| 雪かきポイント | 雪かきをした量(作業時間と、面積 × 積雪の深さで計算。[03](03-go-help.md) を参照) | お年寄りを助ける | 作業分数 × 100(120 分まで)+ 雪の重さ kg × 2(2,000kg まで)。いちばん多くて 16,000 pt |
| 評価ポイント | お年寄りから [いいね](02-thanks.md) をもらった | 感謝される体験 | 星 × 100 pt |
| 勧誘ポイント | 自分が誘った人が初めて雪かきを終えた | 美唄と関わる人を増やす | 誘った人に 500 pt(1 人につき 1 回)。誘われた人にも「はじめての雪かき」200 pt |
| 再会ボーナス | 前の別の依頼でも一緒だった人と、また一緒に雪かきした | 関わりを続けてもらう | 再会した人 1 人につき 150 pt(依頼ごと) |

ポイントの値は仮です。遊んでみて調整します。値はすべて `src/help-requests/score.ts` の定数にあります。

### 式と定数(いまの値)

| 定数 | 値 | 意味 |
| --- | --- | --- |
| `POINTS_PER_MINUTE` | 100 | 作業 1 分あたり |
| `MAX_WORK_MINUTES_FOR_POINTS` | 120 | ポイントに数える作業時間の上限(分) |
| `POINTS_PER_SNOW_KG` | 2 | 雪 1kg あたり |
| `MAX_SNOW_KG_FOR_POINTS` | 2,000 | ポイントに数える雪の重さの上限(kg) |
| `MAX_AREA_M2`(`model.ts`) | 300 | 1 依頼で描ける範囲の上限(㎡)。範囲を描く画面の上限表示も同じ |
| `SNOW_DENSITY_KG_PER_M3` | 100 | 雪の重さ = 面積 × 積雪の深さ × 100kg/㎥ |
| `POINTS_PER_STAR` | 100 | 星 1 つあたり |
| `RECRUIT_POINTS` | 500 | 誘った人が初めて雪かきを終えたとき、誘った人に |
| `FIRST_FINISH_BONUS_POINTS` | 200 | 招待リンクから来た人が初めて雪かきを終えたとき、その人に |
| `REUNION_POINTS_PER_PARTNER` | 150 | 再会した人 1 人につき(依頼ごと) |

- 雪かきポイント = min(作業分数, 120) × 100 + min(雪の重さ kg, 2,000) × 2。参加者全員に同じ点が入る(作業分数は依頼の開始〜終了)
  - 前は「分 × 100 + kg × 10」・面積 2,000㎡ まで だったので、範囲を大きく描くだけで 99,660 点のように跳ね上がっていた
- 勧誘ポイントは「誘われた人が若者として初めて終えた依頼」の終了時刻に入る。招待を記録する前に雪かきを終えたことがある人では入らない
- 再会ボーナスは「終わった依頼で、それより前に終わった別の依頼(done)でも同じ依頼に参加していた若者」の人数 × 150。お年寄りは数えない
- ランキングの内訳の「勧誘」には、誘った 500 pt と、誘われてはじめて終えた 200 pt の両方が入る

## 表示するランキング

- **個人ランキング**: 今シーズンの合計ポイント順
- (余裕があれば)**チームランキング**: 一緒に行った仲間の合計

## 画面イメージ

```text
┌──────────────────┐
│ 今シーズンの順位   │
│                  │
│ 1 位  ゆきお  1,820pt│
│ 2 位  あおい  1,540pt│
│ 3 位  あなた  1,210pt│ ← 自分を目立たせる
│  …               │
│                  │
│ [ 友だちを誘う ]   │ ← 勧誘ポイントへの導線
└──────────────────┘
```

## 「誘った」の判定方法

1. 若者がランキングの画面で「友だちを誘う」を押すと、自分専用の招待コード(ランダムな 10 文字)が作られ、招待リンク `https://liff.line.me/{LIFF ID}/index.html?invite=コード` ができる
   - LINE のユーザー ID はリンクに入れない(ID が知られると、なりすましに使えてしまうため)
   - LINE の中なら `liff.shareTargetPicker` で友だちに招待メッセージ(文 + リンク)を送る。使えなければリンクをコピーする
2. そのリンクから開いた人を「誘われた人」として記録する(どの画面でも `invite-accept.js` が `?invite=` を見つけて `POST /api/invites/accept`)。1 人 1 回だけ。自分自身のコード・すでに記録済み・持ち主のいないコードは無視
3. 誘われた人が **初めて雪かきを終えたとき** に、誘った人へ 500 pt、誘われた人へ 200 pt(登録だけでは入らない)

## いまできていること

- ランキング画面で「デイリー(日本時間の今日)/ 総合」を切り替えて、順位・名前・ポイントを表示。自分を目立たせ、自分の内訳(雪かき・評価・勧誘・再会)も出す
- 4 種類のポイントをすべて合計する(上の式)。計算は純粋関数: `score.ts`(式と定数)・`bonuses.ts`(勧誘・再会の判定)・`ranking.ts`(集計)・`request-points.ts`(お疲れ様の画面の内訳)
- 「友だちを誘う」ボタン(招待リンク)。招待コードは `invite_codes`、だれがだれに誘われたかは `referrals` の表(`src/invites/`)
- お疲れ様の画面に、その依頼で入った再会ボーナス(だれと再会したか)・はじめての雪かきボーナスを出す
- 画面のいちばん上に「仲間ゲージ」(美唄の仲間を 2 倍に)。仲間 = 終わった依頼に関わったお年寄りと若者の重複なしの人数、目標 = シーズン開始時の仲間の数(`COMMUNITY_BASELINE` = 10、仮)× 2。`GET /api/community`(`src/help-requests/community.ts`)
- 未実装: チームランキング、シーズンの区切り
