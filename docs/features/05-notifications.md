# 05. 通知(若者向け)

## 何のための機能?

若者に「今が出番だ」と気づいてもらうための LINE 通知です。2 種類あります。

| 通知 | 内容 | タイミング |
| --- | --- | --- |
| 積雪予報 | 「明日の朝、美唄で 15 cm 積もりそうです」 | 雪が多く降りそうな日の前日の夕方 |
| 依頼のまとめ | 「いま 3 件、助けを待っている家があります」 | 朝 7 時 + 日中は 1 時間に 1 回まで |

## 通知を「まとめる」理由

依頼が入るたびに通知すると、若者にとってうるさくなり、通知を切られてしまいます。
そのため、**決まった時間に件数をまとめて 1 通** にします。

- 待っている依頼が 0 件なら送らない
- 前回の通知から件数が変わっていなければ送らない

## 天気予報の取り方

無料で使える天気予報 API(= 天気のデータを取り出せる窓口)を使います。

- **Open-Meteo に決定**(登録不要・無料。降雪量の予報が取れる。商用でない利用は無料)
- 美唄市のおおよその位置(緯度 43.33、経度 141.85)の予報を取る
- 「24 時間の降雪量が〇 cm 以上」なら通知する。しきい値は仮で 10 cm

## いまできていること(積雪予報)

- `GET /api/weather` … 美唄の「これから 24 時間の降雪量」と「いまの積雪の深さ」を返す。大雪(10 cm 以上)なら通知文も返す
- LIFF のトップ画面に「美唄の雪の予報」を表示
- `npm run notify:weather` … 予報を見て、送る予定の文面を表示する(**送らない**おためし)
- `npm run notify:weather -- --send` … 大雪なら **友だち全員に本当に送る**(まだ一度も送っていない)
- 仕組みは `src/weather/`、決まった時間に自動で動かすのは公開方法が決まってから

## デモで作る範囲

- 天気予報 API から美唄の降雪量を取得して表示する
- 「通知を送る」ボタン(管理者用)を押すと、まとめ通知が届く
  (自動で決まった時間に送る仕組みは、公開方法が決まってから)

## あと回しにすること

- 若者ごとの通知の ON / OFF、時間帯の設定
- 自分の住んでいる地域だけの通知
