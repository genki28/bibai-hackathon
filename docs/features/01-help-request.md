# 01. 助けを呼ぶ(お年寄り向け)

## 何のための機能?

お年寄りが、**ボタンを押すだけで** 雪かきの助けを呼べるようにします。
文字を打つ、地図で場所を探す、といった操作はさせません。

## 使い方

1. LINE のトーク画面下のメニュー(リッチメニュー)で **「たすけて」** を押す
2. 確認画面で **「呼ぶ」** を押す
3. 「お願いしました。だれかが来たら LINE でお知らせします」と出る
4. 若者が向かうと「〇〇さんが向かっています」と LINE に届く

## 画面イメージ

```text
┌──────────────────┐
│                  │
│  雪かきを        │
│  おねがいしますか?│
│                  │
│ ┌──────────────┐ │
│ │    よぶ       │ │  ← 大きなボタン 1 つ
│ └──────────────┘ │
│     やめる        │
└──────────────────┘
```

## 依頼に入る情報

| 項目 | どう集める | 備考 |
| --- | --- | --- |
| だれの依頼か | LINE のユーザー ID(自動) | 入力不要 |
| 場所 | **最初の 1 回だけ** 登録した住所(または家族が代わりに登録) | 毎回は聞かない |
| どのくらい大変か | 「すこし」「たくさん」の 2 択(任意) | 省略しても OK |
| いつまでに | 自動で「今日中」 | デモでは固定 |
| 状態 | 待っている → 向かっている → 完了 | 自動で変わる |

## いまできていること

- 画面: `public/liff/help-request.html`(見た目)と `help-request.js`(動き)。雪の多さ(すこし / ふつう / たくさん)を選んで「よぶ」を押すと依頼が保存される
- API: `POST /api/help-requests`(依頼を登録)、`GET /api/help-requests`(待っている依頼の一覧)。同じ人が待っている依頼を出していれば、二重には作らない
- 保存先はいまサーバーのメモリ(再起動で消える。Supabase につなぐときに置き換える)
- 場所(住所)はまだ扱っていない
- 見た目は Gemini 担当の人が作る。作業メモは [Gemini 向け作業メモ](../guides/help-request-form-for-gemini.md)

## デモで作る範囲

- 「たすけて」ボタン → 確認 → 依頼が登録される
- 場所は事前に登録した住所(デモ用の架空の住所)を使う
- 依頼の一覧を若者側([03 助けに行く](03-go-help.md))から見られる

## あと回しにすること

- 家族が代わりに依頼する機能
- 依頼の取り消し、日時の指定
- 電話での依頼(LINE を使えない人向け)
