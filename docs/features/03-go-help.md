# 03. 助けに行く(若者向け)

## 何のための機能?

若者が、助けを呼んでいる家を **地図から選んで** 雪かきに行けるようにします。
雪かきの終わりに **消費カロリーとスコア** を見せて、運動した実感とゲームらしさを出します。

## 使い方

1. リッチメニューの **「助けに行く」** を押す(LIFF 画面が開く)
2. 地図に、助けを待っている家のピンが出る
3. ピンを選んで **「ここに行く」** を押す → お年寄りに「向かっています」と届く
4. 着いたら **「雪かき開始」** を押す(時間の計測が始まる)
5. 終わったら **「雪かき終了」** を押す
6. 結果画面に、作業時間・消費カロリー・獲得ポイントが出る

## 画面イメージ

```text
┌──────────────────┐      ┌──────────────────┐
│  [ 地図 ]         │      │  おつかれさま!    │
│    📍  📍         │      │                  │
│        📍         │  →   │ 作業時間  45 分   │
│                  │      │ 消費      320 kcal│
│ ○○町 1 丁目付近   │      │ 獲得     +150 pt  │
│ [ ここに行く ]    │      │ (再会ボーナス +50)│
└──────────────────┘      └──────────────────┘
```

## 消費カロリーの出し方(目安)

```text
消費カロリー(kcal) = METs × 体重(kg) × 時間(h) × 1.05
```

- METs(= 運動の強さを表す数字)は、雪かきでおよそ 5〜6
- 体重は登録してもらうか、入力がなければ 60 kg として計算する
- あくまで目安であることを画面に書いておく

## 複数人での雪かき

- 1 つの依頼に **何人でも参加できる** ようにする(友だちを誘って行ける)
- 同じ依頼に参加した人同士は「一緒に雪かきした」記録が残り、次に一緒に行くと [ランキング](04-ranking.md) の再会ボーナスになる

## デモで作る範囲

- 地図に依頼のピンを出す(場所はデモ用の架空の住所)
- 「ここに行く」→「開始」→「終了」→ 結果画面
- カロリーは上の式で計算、ポイントを加算

## あと回しにすること

- 現在地からの距離順の並べ替え、道案内
- 写真で「やる前 / やった後」を残す機能
- 雪の量の自動計測
