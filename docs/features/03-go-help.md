# 03. 助けに行く(若者向け)

## 何のための機能?

若者が、助けを呼んでいる家を **地図から選んで** 雪かきに行けるようにします。
雪かきの終わりに **消費カロリーとスコア** を見せて、運動した実感とゲームらしさを出します。

## 使い方

1. リッチメニューの **「助けに行く」** を押す(LIFF 画面が開く)
2. 地図に、助けを待っている家のピンが出る
3. ピンを選んで **「ここに行く」** を押す → お年寄りに「向かっています」と届く
4. 着いたら **「雪かき開始」** を押す(時間の計測が始まる)
5. 終わったら **「雪かき終了」** を押す
6. 結果画面に、作業時間・消費カロリー・獲得ポイントが出る

## 画面イメージ

```text
┌──────────────────┐      ┌──────────────────┐
│  [ 地図 ]         │      │  おつかれさま!    │
│    📍  📍         │      │                  │
│        📍         │  →   │ 作業時間  45 分   │
│                  │      │ 消費      320 kcal│
│ ○○町 1 丁目付近   │      │ 獲得     +150 pt  │
│ [ ここに行く ]    │      │ (再会ボーナス +50)│
└──────────────────┘      └──────────────────┘
```

## 消費カロリーの出し方(目安)

```text
消費カロリー(kcal) = METs × 体重(kg) × 時間(h) × 1.05
```

- METs(= 運動の強さを表す数字)は、雪かきでおよそ 5〜6
- 体重は登録してもらうか、入力がなければ 60 kg として計算する
- あくまで目安であることを画面に書いておく

## 雪の量の出し方(案)

写真から立体を作る方法(3D スキャン・写真測量)は、雪が真っ白で手がかりが少なく、処理も重いので使わない。
代わりに **計算で求める**。

```text
雪の量(m³) = 雪かきした面積(m²) × 積もった雪の深さ(m)
雪の重さ(kg) = 雪の量(m³) × 100(新雪の目安)
```

| 値 | 取り方 |
| --- | --- |
| 面積 | 若者が地図の上で雪かきした範囲を指でなぞって囲む。または「玄関まわり」「駐車場 1 台分」などから選ぶ |
| 深さ | Open-Meteo から、その日のその場所の積雪の深さ(`snow_depth`)を自動で取る(取れることは確認済み) |

結果画面で「〇 kg 運びました!」と出すと達成感が出る。

### 写真の使いみち(案)

量を測るためではなく、**不正対策とお年寄りへの報告** に使う。

- 雪かきの後に写真を 1 枚撮る → AI が「すこし / ふつう / たくさん」の 3 段階で判定する(AI の利用料がかかる)
- AI とつながらないときは、若者が自分で 3 段階から選べるようにしておく
- 完了メッセージに写真を付けて、お年寄りが見てから「いいね」を押せるようにする
- 写真には家や顔が写るので、本人とお年寄りだけが見られる設定にする

## 複数人での雪かき

- 1 つの依頼に **何人でも参加できる** ようにする(友だちを誘って行ける)
- 同じ依頼に参加した人同士は「一緒に雪かきした」記録が残り、次に一緒に行くと [ランキング](04-ranking.md) の再会ボーナスになる

## いまできていること

- 一覧(エリアで絞り込み・5 件ずつ)→ 大まかな地図 → 確認 → 参加 → 本人確認(デモ)→ 詳しい地図 → 到着 → 集合 → リーダーが開始 → 雪かき中(経過時間)→ 範囲を地図に描く → 終了 → お疲れ様、まで動く
- 1 つの依頼に 5 人まで参加でき、最初に参加した人がリーダー
- 作業時間・消費カロリー(5.5 METs・60kg)・面積・雪の重さ(積雪は Open-Meteo、取れなければ 0.3m)からポイントを計算
- 未実装: 再会ボーナス、写真、現在地からの距離順、LINE の ID トークンでの本人確認(いまは userId を信じている)
- 画面と API の一覧は [pages.md](pages.md)

## デモで作る範囲

- 地図に依頼のピンを出す(場所はデモ用の架空の住所)
- 「ここに行く」→「開始」→「終了」→ 結果画面
- カロリーは上の式で計算、ポイントを加算
