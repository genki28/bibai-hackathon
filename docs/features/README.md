# 機能一覧

アプリ全体の目的は [何を作るか](../product.md) を見てください。
1 つの機能を作るときは、その機能のページを Claude に渡して「このページの『デモで作る範囲』を作って」と頼むと進めやすいです。

## 全体の流れ

```text
お年寄り                       アプリ                         若者
───────                       ──────                         ──────
「たすけて」を押す ─────────▶ 依頼を登録 ──────▶ 通知(まとめて) ─▶ 地図で依頼を選ぶ
                                                                     │
                              「向かっています」◀───────────────────┘
                                                                     │
                                                              雪かき開始 → 終了
                                                                     │
「いいね」を押す ◀──────────── 完了を知らせる ◀─────────────────────┘
       │
       └──────────────────▶ ポイント加算 ──────▶ ランキングに反映
```

## 機能

| 番号 | 対象 | 機能 | ひとこと |
| --- | --- | --- | --- |
| 01 | お年寄り | [助けを呼ぶ](01-help-request.md) | ボタンを押すだけで依頼できる |
| 02 | お年寄り | [いいね](02-thanks.md) | 来てくれた若者にお礼。評価ポイントになる |
| 03 | 若者 | [助けに行く](03-go-help.md) | 地図で選ぶ → 開始 → 終了 → カロリーとスコア |
| 04 | 若者 | [ランキング](04-ranking.md) | 4 種類のポイントで競う |
| 05 | 若者 | [通知](05-notifications.md) | 積雪予報と、助けを待つ人のまとめ通知 |

## 共通のこと

- **使う人の区別**: 最初に「助けてほしい(お年寄り)」か「助けたい(若者)」かを選んでもらい、以後はそれぞれ専用のメニュー(リッチメニュー)を出す(**実装済み**)
  - 友だち追加した人には「利用者登録メニュー」が出る。押すか、友だち追加の直後に、トークに「助けてほしい」「助けたい」のボタンが届く
  - 選ぶと役割を保存し、「助けてほしい人のメニュー」(たすけて / 登録の変更)か「助けたい人のメニュー」(助けに行く / ランキング / 登録の変更)に切り替わる
  - 「たすけて」「助けに行く」「ランキング」は、画面ができるまで LIFF のトップを開く
  - 役割はいまサーバーのメモリに保存(再起動で消える。Supabase につなぐときに置き換える)。仕組みは `src/bot/registration.ts` と `src/users/`
- **本人確認**: マイナンバーカード連携は見た目だけの仮実装(モック)
- **お年寄り向けの画面**: 文字は大きく、1 画面にボタンは 1〜2 個まで、入力はできるだけさせない

## 作る順番のおすすめ

1. 使う人の区別(お年寄り / 若者)
2. 01 助けを呼ぶ → 03 助けに行く(ここまでで「つながる」デモになる)
3. 02 いいね → 04 ランキング(ゲームらしさが出る)
4. 05 通知(最後。デモでは手動で送る形でも OK)
