# デザインの方針

## 配色と文字

助けを呼ぶフォームを除く11画面を、白・紺・朱色に揃えます。白い余白で区切り、説明は必要な場所に置き、件数・人数・順位・作業時間・獲得ポイントを大きく見せます。操作や成果にだけ朱色を使います。機能と画面遷移は [画面一覧](features/pages.md) のままです。

| 用途 | 色 |
| --- | --- |
| 背景 | 白 `#FFFFFF` |
| 本文・罫線 | 紺 `#192E49` |
| 主な操作・成果 | 朱色 `#B73E2C` |
| 補足 | グレー `#606C7B` |
| 控えめな面 | `#F3F5F7` |

## 比較できるふたつの案

`/liff/design-preview.html` から選べます。通常はドット絵です。本文・見出し・ボタン・数字・比較ページまで、どちらの案でも DotGothic16 を使用します。選んだ案は同じタブ内の画面遷移で引き継ぎ、タブを閉じると初期状態に戻ります。保存が使えない環境でも、URLで指定したページには反映されます。

| 案 | 若者側 | お年寄り側 |
| --- | --- | --- |
| スポーツ誌風 `?design=editorial` | DotGothic16 で、大きな数字と罫線を中心にする | 同じドット書体で、大きな文字と操作ボタンを使う |
| ドット絵 `?design=pixel` | 本文・見出し・ボタン・数字を DotGothic16 に統一。雪の町、角のある枠、ドットのスコップとトロフィーを使う | 同じ書体で本文20px・行間1.9。状態を一か所にまとめ、派手な動きを足さない |

- ドット絵の書体は400のみを使用し、擬似的な太字で字形をつぶさない。
- Google Fonts は既存の配信サービスを使用。`display=swap` と端末の代替書体で、読み込み中も文字を表示する。
- スポーツ誌風の本文16px、お年寄り側19px。補足はそれぞれ14px・16px以上を基本にする。
- 操作ボタンは56px以上、お年寄り側72px以上。キーボード操作でも選択位置が分かる枠を付ける。
- 状態は色だけに頼らず、到着・移動中などの文字を添える。
- 内容は最大520px。下部メニューと本文が重ならない余白を取る。

## 各画面

| 画面 | 見せ方 |
| --- | --- |
| トップ | 短いメッセージと参加／助けを呼ぶ入口。接続情報は折りたたむ |
| 依頼一覧 | 件数を大きく表示し、エリア、参加人数、雪の量を簡潔に並べる |
| 場所・参加確認 | 地図と依頼情報をまとめ、参加操作を朱色にする |
| 本人確認 | 同じ配色・書体に揃える。デモであることと写真の扱いの説明は残す |
| 集合 | 集合人数と参加者名簿、到着状態を見せる |
| 雪かき中 | 既存の動くドット絵を残し、経過時間とレベルを読みやすくする。ドット絵は参加者の人数ぶんの若者が左右から真ん中の雪の山に向き合う(途中で増えた人は歩いて登場、頭の上に名前、自分は黄金色 + ▼、リーダーは王冠)。**隠し機能**: 絵をタップするとコンボの演出。**スコップ計**の操作・回数・推定重量も表示する |
| 範囲の記録 | 地図を広く取り、面積と完了操作を目立たせる |
| 結果 | CLEAR、獲得ポイント、活動の記録。計算方法の説明は折りたたむ |
| ランキング | 順位を数字で見せる。自分のポイント内訳は折りたたむ |
| お年寄りの待機 | 進み具合と現在の状態をまとめる。向かっている人がいる間は、大きな地図(家の印と若者のアイコン・名前)と、1 人ずつのカード(「あと約〇分」を大きく)。取り消す操作は控えめにする |
| お礼 | 来てくれた人ごとに大きな星を選び、お礼を送る |

## 実装と変更範囲

- `snow-ui.css` は11画面共通、`snow-pixel.css` は `data-design="pixel"` が付いた画面だけに適用する。
- `design-theme.js` がURLの `design` を検証し、`sessionStorage` に選択を保存する。任意の値をCSSやURLへ埋め込まない。
- 比較ページの選択が実際の画面へ移動する。比較専用の別の画面内容を複製しない。
- **助けを呼ぶフォーム `help-request.html` / `help-request.js` は変更しない。新しいCSS・テーマ選択処理も読み込ませない。** 既存の `template.css`、共通処理、`loading.css` も変更しない。
- `images/pixel-town.svg`、`pixel-shovel.svg`、`pixel-cup.svg` は整数のマス目で作った図形。追加のライブラリは不要。
- 点数・報酬・ランキングの計算や、通知・保存の仕組みは既存のまま。
- 動きを減らす設定では、新しいCSSの演出と既存の数え上げ・紙吹雪を止める。作業中のドット絵も既存の設定対応を使う。

作業中のドット絵は参加者が左右から雪の山に向き合い、途中参加者は歩いて登場します。名前・自分の印・リーダーの王冠と、タップ時のコンボ演出は既存のままです。スコップ計をオンにすると回数と推定重量を表示し、すくうたびに自分のキャラクターが雪を投げます。回数はポイントに加算しません。

## 確認

`TEST_MODE=true`、SupabaseとLINEの接続設定は空で起動し、架空の利用者で確認します。本物の通知は送りません。

- 参加→本人確認済み→到着→集合→作業→範囲記録→結果→ランキング、お年寄りの待機→お礼の流れを確認する。
- 両方の見た目、320px・390px・幅の広い画面、テーマの引き継ぎと切り替え、空の一覧、折りたたみを確認する。
- `npm test` と `npm run typecheck` を実行する。
- LINE内の認証・実際のカメラ・本物の通知は実機で別途確認する。

## アイコン(2026-11-23 から)

画面の絵文字は、ChatGPT で作ったドット絵の SVG アイコン(`public/liff/icons/*.svg`、16×16 のマス目・紺 / 朱色 / 白 / 水色の 4 色)に置き換えた。HTML では `<img class="ui-icon" src="./icons/〇〇.svg" alt="" aria-hidden="true" />`、JavaScript では `common.js` の `icon(name)` / `setIconText(element, name, text)` を使う。大きく出すときは `ui-icon is-big`。LINE のトークに送る文(招待・お知らせ)は画像を入れられないので、絵文字のまま。

| 名前 | 使う場所 |
| --- | --- |
| test | 🧪 のデモ用ボタン・テストの小窓 |
| pin / phone / crown / speaker / mute / antenna | 位置・スコップ計・リーダー・音の実況・音の合言葉 |
| check / hourglass / house / snowman / cheer / party | 状態の表示(着いた・待っている・雪かき中・向かっている・終わった) |
| snowflake / warning / idcard / selfie / oops / letter | 依頼の雪の多さ・本人確認・お礼 |
| hand / pencil / trash / goose / runner | 範囲の記録・テストの消去・仲間ゲージ・地図の人 |
