# デザインの方針

画面を作るとき・直すときは、このページに合わせます。

## コンセプト: 「ユキカキ・レイド ― 美唄の仲間を 2 倍に」

- **今どきのソシャゲの高揚感**: 雪かきを「みんなで挑むレイドバトル」として見せる。依頼 = クエスト、参加者 = パーティー、終了 = リザルト画面
- **雪がテーマ**: 冬の夜空の深い青に、オーロラのような光と、ゆっくり舞う雪。白い雪の粒・氷のきらめきでワクワク感を出す
- **美唄の仲間を 2 倍に**: アプリ全体の目的を、画面の中の「×2」で見せる。美唄に関わった人の数を「仲間ゲージ」で表し、目標は今の 2 倍。勧誘や再会が、ゲージを伸ばす一番の方法だと伝わるようにする
- **美唄らしさ**: 宮島沼に来るマガン(渡り鳥。群れで飛ぶ)を「仲間が集まる」象徴として使う。群れが増えていく演出は、仲間が倍になることと重なる

## 2 つのトーン

| 対象 | トーン | 理由 |
| --- | --- | --- |
| 若者(助けたい人) | **ゲーム寄り**: 夜空の青・オーロラ・光るボタン・大きな数字・演出多め | ジムに行かない若者が「やってみたい」と思える高揚感 |
| お年寄り(助けてほしい人) | **やさしい冬**: 明るい雪景色・あたたかいオレンジ・文字とボタンは大きく、演出は控えめ | 迷わず押せることが最優先。ゲームっぽさで不安にさせない |

同じアプリだと分かるように、雪の粒・角の丸み・字の形はそろえる。

## 色

| 名前 | 色 | 使いどころ |
| --- | --- | --- |
| 夜空(背景) | `#0B1026` → `#1B2A5C` のグラデーション | 若者の画面の背景 |
| 氷の青(メイン) | `#4FD1FF` | 主なボタン・選択中・進行中 |
| オーロラの紫 | `#8B5CF6` | アクセント・グラデーションの相方 |
| 黄金(報酬) | `#FFC94D` | スコア・ポイント・ランキング上位・×2 |
| 雪の白 | `#F4F8FF` | 文字・カードの縁 |
| あたたかいオレンジ | `#F26B1D` | お年寄りの主なボタン(「よぶ」「送る」) |
| 雪景色(背景) | `#FFF8F1` → `#EAF4FF` | お年寄りの画面の背景 |
| 危険 | `#E5484D` | 取り消し |

文字と背景の明るさの差は、ふつうの文字で 4.5:1 以上にする(読みやすさの基準)。

## 文字

- 見出し・数字: **M PLUS Rounded 1c**(丸みのある太い字。ゲームらしさ)。読み込めないときは端末の字
- 本文: 端末の標準の字(Hiragino Sans など)
- 数字は大きく、太く。スコアやポイントは数えあがる演出(カウントアップ)

## 部品

- **カード**: 半透明のガラスのような板(背景が少し透ける)、角は大きく丸く(16〜20px)、細い光の縁
- **ボタン**: 主なボタンは氷の青 → オーロラの紫のグラデーションで、ふわっと光る。押すと少し沈む。高さ 52px 以上(お年寄りは 72px 以上)
- **下のタブ**(若者): ガラスの帯。選んでいるタブは光る
- **バッジ**: 称号(ゆきだるま → つらら → ふぶき → ゆきの勇者)、リーダーの王冠
- **仲間ゲージ**: 「美唄の仲間 〇〇人 / 目標 〇〇人(×2)」。マガンのアイコンが増えていく
  - 数え方: 仲間 = シーズン開始時の仲間の数 + 終わった依頼(done)に新しく関わった人(依頼したお年寄り + 参加した若者)の重複なしの人数。目標 = シーズン開始時の仲間の数(`COMMUNITY_BASELINE`、仮に 10 人)× 2。`GET /api/community` が `{ members, goal, baseline }` を返す(`src/help-requests/community.ts`)

## 画面ごとの見せ方(若者)

| 画面 | 見せ方 |
| --- | --- |
| ランキング | 上位 3 人は金・銀・銅の大きなカード。自分の順位は光る帯で固定表示。上に「仲間ゲージ」 |
| 助けに行く | 依頼を「クエスト」のカードで並べる(雪の多さ = 難易度の雪の結晶 1〜3 個、参加人数 〇/5) |
| 確認の小窓 | 「このクエストに参加しますか?」をレイドの参加画面のように |
| 待機中 | 「パーティー集結中」。参加者のアイコンが円く並び、そろうと光る |
| 雪かき中 | **ドット絵のゲーム画面**。冬の夜の美唄の町の背景に雪が降り、参加者の人数ぶんのスコップの若者が、左右から真ん中の雪の山に向き合って雪かきする(途中で人が増えると横から歩いて登場して「JOIN!」。頭の上に名前、自分は黄金色 + ▼、リーダーは王冠)。経過時間で雪の山が減り、投げた雪は外側に積もる。ときどきマガンの群れが横切る(レベルが上がるほど群れが大きい)。**隠し機能**: 絵をタップすると自分がすばやく投げて「+1」、続けると「COMBO x〇」、節目で COOL! / GREAT! / SUPER!(画面にはタップの説明を出さない。休憩中などに気づいた人が楽しめるおまけ。見た目だけで、スコアには入らない)。上に「雪かきレベル Lv.〇」と進み具合のマス、経過時間は大きく |
| お疲れ様 | 「QUEST CLEAR!」の演出。スコアがカウントアップ、雪の紙吹雪。仲間ゲージが伸びる |

## 作りのメモ

- 色・ボタン・カード・タブ・ゲージなど共通の見た目は `public/liff/template.css`(色は `:root` の変数)。夜空・オーロラ・舞う雪も CSS だけ(画像なし)
- カウントアップと雪の紙吹雪は `public/liff/effects.js`、仲間ゲージは `public/liff/community-gauge.js`
- 雪かき中の背景と主人公の画像は ChatGPT で生成(`public/liff/images/working-bg.png`・`working-hero.png`。主人公は 4 コマを横に並べた 1 枚)。その上に Canvas で、雪の山・降る雪・マガン・文字の演出を描く: 動かし方 `pixel-snow.js`、描く部品 `pixel-draw.js`、参加者の並べ方 `pixel-crew.js`、マガン・王冠(スプライト = 文字の並び + 色の対応表)とドットの文字 `pixel-sprites.js`、レベル・雪の山・コンボ・コマの計算 `pixel-game.js`(テストは `tests/pixel-*.test.ts`)。362×272 ドットに描いて拡大する
- 字(M PLUS Rounded 1c)は各ページの `<head>` で Google Fonts から読み込む

## 動き

- 雪はゆっくり舞う程度。点滅や激しい動きはしない
- 端末で「動きを減らす」設定の人には、動きを止める(`prefers-reduced-motion`)

## お年寄りのフォーム(help-request.html)

担当の方がデザインしています。色やボタンの大きさは、上の「お年寄り」のトーンと「あたたかいオレンジ」に合わせてもらえると統一感が出ます。
