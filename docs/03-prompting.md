# 3. AI への頼み方

プログラミングの知識はいりません。「新しく入った優秀な同僚に、口頭で仕事を頼む」つもりで書けば十分です。

## 伝えると良い 3 つ

1. **何がほしいか** — 画面? 機能? 文章?
2. **誰が・どう使うか** — 「観光客がスマホで見る」など
3. **できあがりのイメージ** — 「ボタンを押したら一覧が出る」など

### 例

| いまいち | 良い |
| --- | --- |
| いい感じのページ作って | 美唄の焼き鳥店を紹介するトップページを作って。スマホで見る人が多いので縦長で。店名・写真・一言コメントが並ぶ感じ |
| バグってる | 「登録」ボタンを押しても何も起きない。さっきまでは一覧に追加されていた |
| もっとおしゃれに | 文字が小さくて読みにくい。見出しを大きく、色は落ち着いた緑系にして |

## 便利な言い回し

- 「**作る前に、どう作るか教えて**」 — いきなり作らせず、計画を先に見る
- 「**動かして確認して**」 — 作りっぱなしを防ぐ
- 「**小学生にもわかるように説明して**」 — 説明が難しいとき
- 「**さっきの変更を取り消して**」 — 気に入らなかったとき
- 「**いまの状況をまとめて**」 — 迷子になったとき
- 「**ほかの案も 2 つ出して**」 — 比べて選びたいとき

## うまくいかないとき

- **同じ直しを 3 回頼んでも直らない** → 頼み方を変える。「そもそも別のやり方はない?」と聞く。
- **話がこんがらがってきた** → `/save-work` で保存してから、新しい会話を始める。
- **AI が自信満々でも間違うことはある** → 必ず自分の目で動きを確かめる。

## やってはいけないこと

- パスワード・API キー・個人情報を貼り付ける
- 中身がわからないまま「削除」「上書き」「force」に OK する
