# 何を作るか

チームで話して決まったことを書いていきます。空欄があっても大丈夫です。
Claude に「product.md を一緒に埋めたい」と頼むと、質問しながら整理してくれます。

## ひとことで言うと

**雪かきで困っているお年寄りと、体を動かしたい若者をつなぐ LINE アプリ**(仮称: 雪かきアプリ)。

お年寄りがボタンひとつで助けを呼び、若者がゲーム感覚で助けに行きます。
雪かきをきっかけに、**美唄市と関わる人を増やす** ことが本当の目的です。

## 誰の、どんな困りごとを解決する?

| 誰 | 困りごと | このアプリでどうなる |
| --- | --- | --- |
| 美唄のお年寄り | 雪かきが体力的にきつい。頼める人が近くにいない | LINE のボタンを押すだけで助けを呼べる |
| 若者(市内・近隣) | 運動不足。でもジムに通うほどではない | 雪かきが「運動 + ゲーム」になる。ランキングで競える |
| 美唄市 | 関わってくれる人(関係人口)を増やしたい | 雪かきを通じて人が集まり、友だちを誘い、また来てくれる |

## 使う人がやること(3 ステップくらいで)

**お年寄り**

1. LINE のメニューから「たすけて」ボタンを押す
2. 来てくれた若者に「ありがとう(いいね)」を押す

**若者**

1. 地図から助けを呼んでいる家を選ぶ
2. 「雪かき開始」→「雪かき終了」を押す(消費カロリーとポイントが出る)
3. ランキングで自分の順位を見る

## なぜ LINE(LIFF)なのか

- お年寄りでも **新しいアプリを入れずに** 使える(ふだん使っている LINE の中で動く)
- 通知が LINE のトークに届くので、見落としにくい
- 若者側もアプリのインストール不要で、友だちに URL を送るだけで誘える
- (2026-11-23 から)若者向けには、雪かき中に画面を閉じてもスコップ計と位置を読み続けるための **ネイティブアプリ** も作る(`helper-app/`)。LIFF の若者の画面も残す

## 機能の一覧

詳しくは [機能一覧](features/README.md) を見てください。

| 対象 | 機能 | 説明 |
| --- | --- | --- |
| お年寄り | [助けを呼ぶ](features/01-help-request.md) | ボタンを押すだけで雪かきを依頼する |
| お年寄り | [いいね](features/02-thanks.md) | 来てくれた若者にお礼を送る(ランキングの評価になる) |
| 若者 | [助けに行く](features/03-go-help.md) | 地図で選ぶ → 開始 → 終了 → カロリーとスコアを表示 |
| 若者 | [ランキング](features/04-ranking.md) | 評価・雪かきの量・誘った人数・再会ボーナスで競う |
| 若者 | [通知](features/05-notifications.md) | 雪が積もりそうなとき、助けを待つ人がいるときに LINE でお知らせ |

技術的な課題は [技術的な課題](technical-challenges.md) にまとめています。

## デモで必ず見せたいもの

- お年寄りがボタンを押す → 若者の地図にピンが立つ
- 若者が雪かきを終える → カロリーとポイントが出る → お年寄りが「いいね」
- ランキングが動く(誘った人・再会ボーナスが効いている)

## やらないこと(時間が足りないので割り切ること)

- **マイナンバーカードでの本人確認**: 見た目だけの仮実装(モック)にする。発表では「本番ではデジタル認証アプリを使う想定」と説明する
- 雪の量の正確な計測(自己申告や作業時間から推定する)
- 支払い・謝礼のやりとり
