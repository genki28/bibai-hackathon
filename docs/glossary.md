# 用語集

| 言葉 | ひとことで |
| --- | --- |
| リポジトリ | プロジェクトのファイル一式と、その変更履歴が入った箱 |
| GitHub | リポジトリをネット上に置いて、チームで共有する場所 |
| クローン | GitHub のリポジトリを自分の PC にコピーしてくること(最初の 1 回) |
| プル (pull) | みんなの最新の変更を自分の PC に取り込むこと |
| コミット | 変更を「ここまで」と区切って記録すること。セーブポイント |
| プッシュ (push) | 自分のコミットを GitHub に送ること |
| ブランチ | 自分専用の作業場所。本体を壊さずに試せる |
| main | みんなの「本体」のブランチ。直接は触らない |
| プルリクエスト (PR) | 「私の変更を本体に入れてください」という依頼 |
| マージ | ブランチの変更を本体に取り込むこと |
| コンフリクト | 同じ場所を 2 人が別々に変えて、機械が決められない状態 |
| ターミナル | 文字でPCに命令する画面(Mac: ターミナル / Windows: PowerShell) |
| 技術スタック | 何を使って作るかの組み合わせ(言語・道具など) |
| 環境変数 / `.env` | API キーなどの秘密を、コードの外に置いておく仕組み |
| API キー | サービスを使うための合言葉。他人に見せてはいけない |
| デプロイ | 作ったものをネットに公開して、誰でも見られるようにすること |
| バイブコーディング | AI に言葉で頼みながら作る開発のやり方 |
| スキル | Claude Code に登録された「合言葉」。`/start-work` など |
